## Про систему

База описує роботу міського транспорту: депо, машини (автобуси, тролейбуси, трамваї), водії та їх допуски,
маршрути із зупинками і розкладом, зміни, рейси, транспортні картки пасажирів, оплату проїзду і ремонти.

Основні правила:
* водій може виїхати тільки на тому типі транспорту, на який має дійсний допуск;
* машина, що в ремонті, не може вийти на рейс;
* при проході з картки списується вартість по тарифу, баланс не може бути від'ємним;
* машини, водії, маршрути, зупинки і картки не видаляються фізично (soft delete через `deleted_at`);
* для основних таблиць зберігається дата останньої зміни і користувач, який її зробив (`updated_at`, `updated_by`).

## Структура проєкту

* [`docs`](./docs)
  * `schema_init.sql` — таблиці, ключі, обмеження
  * `views_procedures_triggers.sql` — індекси, функції, тригери, збережені процедури, view
  * `test_init_data.sql` — тестові дані
  * `DB_diagram.png` — ER-діаграма
  * `schema.dbml` — схема для [dbdiagram.io](https://dbdiagram.io)
* [`src`](./src) — доступ до даних на Python
  * `repositories.py` — репозиторії (читання з view, запис через збережені процедури)
  * `unit_of_work.py` — Unit of Work, одна транзакція на всі репозиторії
  * `main.py` — приклад роботи
  * `setup_db.py` — створення бази і виконання SQL-скриптів

## Стек
* **СУБД:** PostgreSQL (збережені процедури, функції, view, тригери)
* **Код:** Python 3, psycopg 3
* **Патерни:** Repository, Unit of Work (без ORM)

## Запуск

Потрібні PostgreSQL (користувач `postgres`, пароль `postgres`) і Python 3.

```
pip install -r requirements.txt
python src/setup_db.py
python src/main.py
```

На Windows можна просто запустити `run.bat`.
